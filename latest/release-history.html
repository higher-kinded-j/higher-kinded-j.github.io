Higher-Kinded-J: Composable Effects and Advanced Optics for Java

Release History

What changed in each version of Higher-Kinded-J, and what to do when you move to it. Each release has notes, most with a link from each change to the issue or pull request behind it.

  • Upgrading? Upgrading lists, release by release, what can stop a build that compiled or change what a program does. It also lists every API due for removal in 0.5.0.
  • Following main? Unreleased: 0.4.11 collects the changes since 0.4.10.
  • Looking for a feature? Since which version? names the release that first shipped it.
  • Searching every release at once? The book's search reads every page of this chapter.
